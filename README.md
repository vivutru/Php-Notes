## Lessons

| # | Topic | Description |
|---|-------|------------------|
| 1 | Basics: echo, variables, concatenation | Making a page print text, storing information in labelled boxes, and joining pieces of text together |
| 2 | Environment and basic syntax, booleans | Setting PHP up, and asking yes/no questions like "is this score a pass?" |
| 3 | If statements, switch, do-while | Making the program choose between options, like "discount or no discount" |
| 4 | Operators and precedence | The rules for which maths happens first, plus combining conditions with AND / OR / NOT |
| 5 | Decisions in practice | Using if/elseif and switch for real cases like delivery charges and user roles |
| 6 | Loops (for, while, do-while) | Telling PHP to repeat a task, like adding up 8 ticket sales, without writing it 8 times |
| 7 | Foreach and arrays | Storing a list of things (marks, trips, withdrawals) and going through them one by one |
| 8 | Arrays in depth | Lists with labels (stock by product), adding, removing and summing items |
| 9 | Functions and validation | Packaging code into reusable named blocks, checking data is valid, sorting and looking up results |

Full explanations are in the each labs folders.
